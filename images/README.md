# Dossier Images

## 📸 Images requises

Placez vos images de produits dans ce dossier avec les noms suivants :

1. `extract.jpg` - Image pour la catégorie Extract
2. `static-sift.jpg` - Image pour la catégorie Static-Sift
3. `frozen-sift.jpg` - Image pour la catégorie Frozen-Sift
4. `dry-sift.jpg` - Image pour la catégorie Dry-Sift
5. `weed.jpg` - Image pour la catégorie Weed

## 📐 Recommandations

- **Format** : JPG, PNG ou WEBP
- **Dimensions recommandées** : 600x600px minimum
- **Ratio** : Carré (1:1) ou portrait (3:4)
- **Qualité** : Haute résolution pour un rendu optimal
- **Poids** : Optimisé (< 500KB par image si possible)

## 🎨 Conseils

- Utilisez des images sur fond noir pour correspondre au thème cosmique
- Les images avec un bon contraste fonctionnent mieux
- Assurez-vous que le produit est bien visible et centré
