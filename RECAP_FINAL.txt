📊 RÉSUMÉ DE TOUT CE QUI A ÉTÉ FAIT :
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ Panel Admin Complet:
   📊 Dashboard - Statistiques
   📦 Produits - Formulaire enrichi (farm, vidéo, descriptions, prix multiples)
   🔲 Catégories - Images externes, suppression, 3 par ligne
   🌿 Farms - CRUD complet, logo, pays
   🔔 Services - Gestion contenu home.html
   ⚙️  Paramètres - Nom boutique, liens sociaux

✅ Frontend Dynamique:
   🏠 home.html - Titre + services depuis admin
   📦 products.html - Liste produits depuis API
   🔍 product-detail.html - Détail avec vidéo, farm, bouton Commander
   🔲 categories.html - Grille 3 par ligne, images
   📞 contact.html - Liens sociaux dynamiques

✅ Base de Données:
   - products (avec farm_id, video_url, long_description)
   - categories (avec image_url)
   - farms (nom, logo, pays)
   - services (pour home.html)
   - product_variants (prix multiples)
   - product_gallery (galerie photos)
   - settings (paramètres boutique)

✅ API Cloudflare Workers:
   - /api/products (GET, POST, PUT, DELETE)
   - /api/categories (GET, POST, PUT, DELETE)
   - /api/farms (GET, POST, PUT, DELETE)
   - /api/services (GET, POST, PUT, DELETE)
   - /api/settings (GET, PUT)
   - /api/stats (GET)
   - /api/upload (POST - R2)

# 1. Récupérer depuis GitHub
cd C:\Users\PC\Documents\sssss
git reset --hard origin/cursor/reconfigure-shop-with-cloudflare-ba7c
git pull origin cursor/reconfigure-shop-with-cloudflare-ba7c

# 2. Initialiser base de données
npx wrangler d1 execute algran-db --command="DROP TABLE IF EXISTS products; DROP TABLE IF EXISTS categories; DROP TABLE IF EXISTS services; DROP TABLE IF EXISTS farms; DROP TABLE IF EXISTS product_variants; DROP TABLE IF EXISTS product_gallery; DROP TABLE IF EXISTS settings; DROP TABLE IF EXISTS images; DROP TABLE IF EXISTS orders; DROP TABLE IF EXISTS order_items;" --local
npx wrangler d1 execute algran-db --file=schema.sql --local

# 3. Démarrer API (Terminal 1)
npx wrangler dev --port 8787 --local

# 4. Démarrer serveur web (Terminal 2)
python -m http.server 10000

# 5. Tester
http://localhost:10000/test-products.html    (test simple)
http://localhost:10000/admin.html             (panel admin)
http://localhost:10000/products.html          (liste produits)
