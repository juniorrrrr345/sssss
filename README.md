# Menu Cannabis - Interface Néon Cosmique

Un site web moderne avec un design néon rétro-futuriste pour présenter un menu de produits cannabis.

## 🚀 Fonctionnalités

- **Design Néon Cosmique** : Interface immersive avec effets néon lumineux et animations fluides
- **Fond Animé** : Étoiles scintillantes et effet parallaxe au mouvement de la souris
- **Cartes Produits Interactives** : Effets de survol avec bordures dégradées animées
- **Navigation Moderne** : Barre de navigation fixe en bas avec icônes SVG
- **Animations JavaScript** : 
  - Apparition progressive des éléments au chargement
  - Particules flottantes atmosphériques
  - Effets d'onde au clic
  - Transitions fluides
- **Responsive Design** : Adapté à tous les écrans (mobile, tablette, desktop)

## 🛠️ Technologies Utilisées

- **HTML5** : Structure sémantique moderne
- **CSS3** : 
  - Animations et transitions avancées
  - Dégradés et effets néon
  - Grid Layout pour la disposition
  - Variables CSS pour la personnalisation
- **JavaScript Vanilla** : Animations et interactions sans dépendances
- **Google Fonts** : Polices Bungee et Roboto

## 📁 Structure du Projet

```
├── index.html      # Page principale avec la structure HTML
├── styles.css      # Tous les styles et animations CSS
├── script.js       # Logique JavaScript pour les interactions
└── README.md       # Documentation du projet
```

## 🎨 Catégories de Produits

1. **Extract** - Extraits concentrés
2. **Static-Sift** - Tamisage statique
3. **Frozen-Sift** - Tamisage à froid
4. **Dry-Sift** - Tamisage à sec
5. **Weed** - Fleurs séchées

## 🚦 Installation et Utilisation

1. Clonez ou téléchargez les fichiers du projet
2. Ouvrez `index.html` dans votre navigateur web
3. Aucune installation supplémentaire requise !

## 💡 Personnalisation

### Couleurs
Les couleurs principales peuvent être modifiées dans le fichier CSS :
- Néon rose : `#ff006e`
- Violet : `#8338ec`
- Bleu : `#3a86ff`
- Cyan : `#06ffa5`

### Images
Remplacez les URLs des images dans `index.html` par vos propres images de produits.

### Texte
Modifiez les titres et descriptions directement dans le HTML.
