# Page Produits - Tous les Produits

Une page web moderne et élégante pour afficher des produits avec un design spatial/galactique inspiré.

## 🚀 Fonctionnalités

- **Design moderne**: Interface avec effet spatial et animations fluides
- **Recherche en temps réel**: Recherchez des produits par nom, catégorie ou caractéristiques
- **Grille responsive**: S'adapte à tous les écrans (mobile, tablette, desktop)
- **Cartes produits interactives**: Effets au survol et animations
- **Navigation mobile**: Barre de navigation fixe en bas pour une meilleure UX mobile
- **Effets visuels**: Animations d'étoiles, dégradés colorés, et effets de blur

## 📁 Structure du projet

```
/workspace/
├── index.html      # Structure HTML principale
├── styles.css      # Styles CSS avec animations
└── script.js       # Logique JavaScript (recherche, affichage)
```

## 🎨 Design

- **Palette de couleurs**: 
  - Fond: Dégradé bleu-violet foncé (#0a0e27 → #2d1b4e)
  - Accent: Rose/Magenta (#ff1493, #ff69b4)
  - Texte: Blanc avec variations d'opacité
  
- **Typographie**: Police cursive pour le titre, Arial pour le contenu

- **Effets**: 
  - Backdrop blur pour les cartes et la recherche
  - Animations d'étoiles en arrière-plan
  - Effet parallaxe sur le titre
  - Transitions fluides au survol

## 🛠️ Utilisation

1. Ouvrez `index.html` dans un navigateur web moderne
2. Utilisez la barre de recherche pour filtrer les produits
3. Cliquez sur un produit pour voir ses détails
4. Naviguez avec la barre en bas de page

## 📱 Responsive

- **Desktop**: Grille de 4-5 colonnes
- **Tablette**: Grille de 2-3 colonnes
- **Mobile**: Grille de 1 colonne avec navigation simplifiée

## ⚡ Performance

- Pas de dépendances externes
- Images optimisées via Unsplash
- Code JavaScript vanilla pour une meilleure performance
- CSS optimisé avec animations GPU-accelerated
