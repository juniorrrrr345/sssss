🚀 DÉMARRAGE ULTRA-RAPIDE (3 ÉTAPES)

═══════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────┐
│  ÉTAPE 1 : LANCER LE SCRIPT DE DÉPLOIEMENT                     │
└─────────────────────────────────────────────────────────────────┘

Ouvrez PowerShell dans ce dossier et tapez :

    .\deploy.ps1

OU double-cliquez sur : deploy.bat

Le script va :
  ✅ Installer tout ce qu'il faut
  ✅ Vous connecter à Cloudflare
  ✅ Créer votre base de données
  ✅ Déployer votre API
  ✅ Vous donner l'URL de votre API

─────────────────────────────────────────────────────────────────

┌─────────────────────────────────────────────────────────────────┐
│  ÉTAPE 2 : CONFIGURER L'URL DE L'API                           │
└─────────────────────────────────────────────────────────────────┘

1. Copiez l'URL que le script vous donne (exemple ci-dessous) :
   https://algran-api-xxx.workers.dev

2. Ouvrez le fichier : admin.js

3. Ligne 7, remplacez :
   const API_URL = 'http://localhost:8787';
   
   Par :
   const API_URL = 'https://algran-api-xxx.workers.dev';
   
   (utilisez VOTRE URL, pas l'exemple)

4. Sauvegardez (Ctrl+S)

─────────────────────────────────────────────────────────────────

┌─────────────────────────────────────────────────────────────────┐
│  ÉTAPE 3 : LANCER LE SERVEUR LOCAL                             │
└─────────────────────────────────────────────────────────────────┘

Dans PowerShell, tapez :

    python -m http.server 8000

Puis ouvrez votre navigateur :

    🎛️  Panel Admin : http://localhost:8000/admin.html
    🛍️  Boutique    : http://localhost:8000/products-complete.html
    
    🔑 Mot de passe : admin123
