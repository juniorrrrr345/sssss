### 3️⃣ Page Détails Produit - Photo + Vidéo ✅

**Page:** http://localhost:8005/product-detail.html?id=3

**Comportement actuel :**
Le code affiche TOUJOURS :
1. La vidéo (si video_url existe)
2. La photo (si image_url existe)
3. Les deux (si les deux existent)

**Si vous ne voyez QUE la vidéo :**
→ C'est que le produit n'a **PAS** d'image_url dans la base de données

**Solution :**
1. Allez sur http://localhost:8005/admin.html
2. Cliquez sur "Produits" dans la barre latérale
3. Trouvez le produit concerné
4. Cliquez sur "Modifier"
5. Vérifiez le champ "URL de l'image"
6. Si vide, ajoutez une URL (ex: https://i.imgur.com/xxxxx.jpg)
7. Cliquez sur "Enregistrer"
8. Rechargez la page détails

**Code actuel (product-detail.html) :**
```javascript
// Affiche la vidéo si elle existe
${videoUrl ? `<video>...</video>` : ''}

// Affiche l'image si elle existe
${product.image_url && product.image_url.trim() ? `<img>...</img>` : ''}
```

**Résultat :**
- ✅ Si produit a vidéo + image → Affiche les deux
- ✅ Si produit a seulement vidéo → Affiche la vidéo
- ✅ Si produit a seulement image → Affiche l'image
- ✅ Si produit n'a ni l'un ni l'autre → Affiche placeholder
