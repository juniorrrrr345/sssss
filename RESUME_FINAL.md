## 🎯 Après le merge

### 1. Déployer la boutique

```bash
# Installer les dépendances
npm install

# Lancer localement pour tester
npm run dev

# Déployer sur Cloudflare
npx wrangler deploy
```

### 2. Initialiser la base de données

```bash
# Créer la base D1 et exécuter le schéma
./init-database.sh
```

### 3. Configurer votre boutique

- Accédez au panel admin : `/admin.html`
- Ajoutez vos catégories
- Ajoutez vos produits avec photos
- Configurez vos liens de contact

### 4. Intégrer avec Telegram

- Configurez votre Bot Telegram
- Ajoutez l'URL de votre boutique comme Mini App
- Testez l'expérience dans Telegram
