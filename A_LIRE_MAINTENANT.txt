ÉTAPE 1 : Testez en local (MAINTENANT)

   ✅ Vérifiez que le design est cohérent partout

   ✅ Vérifiez le panel admin


ÉTAPE 2 : Déployez l'API (Quand vous êtes prêt)
------------------------------------------------
   npm install -g wrangler
   wrangler login
   wrangler d1 create algran-db
   wrangler d1 execute algran-db --file=schema.sql --remote
   npm run deploy
   
   📋 Copiez l'URL que vous recevez !


ÉTAPE 3 : Configurez l'URL de l'API
------------------------------------
   Modifiez ces 3 fichiers avec votre URL Workers :
   
   1. config.js (ligne 14)
   2. admin.js (ligne 9)
   3. products-complete.html (ligne 233)
   
   Remplacez : http://localhost:8787
   Par : https://algran-api-xxx.workers.dev
